# BuscarCEP

Aplicação web para consulta de endereços através de um CEP, utilizando JavaScript e a API ViaCEP.

## Sobre o projeto

O BuscarCEP foi desenvolvido como um projeto de estudo durante meus estudos de Front-end.

A aplicação permite que o usuário informe um CEP e consulte automaticamente os dados de endereço, como:

- Logradouro
- Bairro
- Cidade

Também possui validação do CEP informado, mensagens de erro e um botão para limpar os campos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- API ViaCEP

## Funcionalidades

- Consulta de CEP
- Preenchimento automático dos dados
- Validação de CEP com 8 números
- Mensagem para CEP inválido ou não encontrado
- Tratamento de erros na consulta
- Botão para limpar os campos
- Interface responsiva

## API utilizada

O projeto utiliza a [API ViaCEP](https://viacep.com.br/) para realizar as consultas de endereço.

## Objetivo

O objetivo deste projeto foi praticar conceitos de desenvolvimento Front-end, principalmente:

- Manipulação do DOM
- Eventos em JavaScript
- Funções
- Fetch API
- Promises
- Consumo de APIs
- Validação de dados
- Tratamento de erros
